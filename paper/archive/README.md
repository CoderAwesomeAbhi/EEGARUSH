# Manuscript

`main.tex` is a bioRxiv-oriented manuscript draft built from the committed
pipeline outputs. It is written conservatively: it emphasizes subject-wise
validation, reports limitations, and avoids clinical claims.

Build locally with:

```powershell
pdflatex main.tex
pdflatex main.tex
```

The compiled manuscript should be checked manually before submission,
especially author metadata, figure rendering, and any institution-specific
affiliation text.
