# bioRxiv Submission Checklist

This repository can support a bioRxiv submission, but posting cannot be
guaranteed. bioRxiv screens manuscripts for completeness, article type, scope,
plagiarism or duplicate posting, biological relevance, and potential public
harm.

Before submission:

- Confirm all author names, affiliations, and author order.
- Confirm that all authors approve public preprint posting.
- Upload `paper/main.pdf` as the manuscript PDF.
- Include the repository URL in the Data and Code Availability section.
- Use the original PhysioNet dataset citation and DOI.
- Do not claim clinical diagnosis, medical triage, or individual cognitive
  inference.
- State clearly that this is a secondary analysis of a public, de-identified
  EEG dataset.
- Choose an appropriate bioRxiv subject category, likely Neuroscience or
  Bioinformatics depending on final framing.
- Check every figure panel in the PDF after upload conversion.

Recommended cover-letter language:

```text
This manuscript reports a secondary computational analysis of a public
PhysioNet EEG dataset, with newly generated feature tables, subject-wise
machine-learning evaluations, statistical tests, and reproducible code. The
work is not a clinical diagnostic study and makes no medical deployment claim.
```
