# Theory Validation Results

Generated by `scripts/run_theory_validation.py`. No manuscript text was modified by this run.

## Execution Contract

- Outer validation: leave-one-subject-out.
- Hyperparameter protocol: fixed preregistered C=1.0; no label-dependent hyperparameter search was performed.
- Feature set: 200 per-channel features from the requested 8-channel intersection: F3, F4, F7, F8, O1, O2, T3, T4.
- MAT calibration split: first 60 s of resting windows used for calibration; those windows are excluded from scoring.
- STEW calibration split: first 50% of each subject's cached rest rows by row order used for calibration because the parquet has no timing metadata.
- Duration curves: outer LOSO using the same fixed-C protocol; only logistic_l2 is used for the duration curve to isolate baseline length.
- Negative controls: 1000 within-subject label permutations on nested out-of-fold scores for the best observed MAT and STEW configurations.

## Non-Hallucination Notes

- STEW calibration-duration analysis was not run because the cached STEW parquet contains no timing columns.
- Any poor AUCs in the tables above are retained as failures rather than filtered out.
- The permutation p-values are empirical p = (1 + count(null AUC >= observed AUC)) / (1 + valid permutations).
- Negative-control permutations shuffle labels on already nested out-of-fold scores; they test score-label association, not retrained-model instability.
