# Theory Claim Ledger

Scope: read-only audit of `paper/tex/main.tex`, Python analysis scripts, and existing result artifacts. No manuscript claims were edited and no analysis scripts were executed during this audit.

| Claim | Code Evidence |
|---|---|
| **The manuscript title and abstract claim an "Invariant Cognitive-Effort Axis" or invariant low-dimensional workload axis.** | Unsupported as an invariance claim. `scripts/run_all_journal_upgrade.py` implements SNWA as rest median/MAD subject normalization plus fold-wise feature ranking and a 1D logistic model, but no formal invariance test, source-space model, alignment theorem, Procrustes/CCA/RSA analysis, or cross-dataset invariant-axis test is implemented. Source localization sections in `main.tex` remain TODO/future work. |
| SNWA improves MAT workload decoding after leakage-aware LOSO validation. | Supported for MAT by `scripts/run_all_journal_upgrade.py` and `outputs_journal_upgrade/tables/table_snwa_metrics_by_k.csv`: SNWA K=8 reports AUC 0.7606185, F1 0.5667856, Brier 0.1843779. |
| SNWA is a biological method that isolates fronto-hippocampal theta rhythm from thalamocortical alpha disinhibition. | **Unsupported as a biological mechanism.** SNWA operates on scalp sensor features and rest-normalized tabular feature deltas. There is no source localization, hippocampal source model, thalamocortical model, or alpha disinhibition assay in the executable scripts. |
| Workload should be modeled as subject-specific feature manifolds rather than pooled absolute EEG amplitudes. | Partially supported as an interpretation. LOSO and cross-dataset failures support subject and dataset heterogeneity, but no executable manifold geometry analysis establishes a manifold model. Riemannian exploratory scripts exist, but current outputs do not show strong transfer. |
| Random-window validation inflates performance relative to subject-held-out validation. | Supported in principle by `scripts/run_all_journal_upgrade.py`, which includes leakage/random-window demos, and by the contrast between random-window style claims and LOSO metrics. Exact percentage inflation claims should be tied to the generated leakage table before publication. |
| The repository analyzes MAT, STEW, and DS007262 as three public EEG workload datasets. | Supported by `scripts/multi_dataset_pipeline.py`, which loads MAT/STEW/DS007262-style features, harmonizes common features, and writes `results/multi_dataset/all_metrics.csv`. |
| The main feature extractor includes time-domain statistics, Hjorth parameters, spectral bands, ratios, regional features, hemispheric features, and pairwise correlations. | Supported by `src/eeg_cogstates/features.py`: per-channel statistics/Hjorth/bandpower/ratios and window-level regional, hemispheric, and correlation features are implemented. |
| The MAT loader uses optional filtering, rereferencing, and ICA but defaults to raw microvolt conversion for feature extraction. | Supported for MAT by `src/eeg_cogstates/dataset.py`, where `filter_band`, `reref`, and `ica_artifact` default to inactive values and EDF data are converted to microvolts. |
| Ratio measures are reference-independent or cancel the reference by division. | **Unsupported and scientifically unsafe.** No script proves reference invariance. In general, rereferencing changes both numerator and denominator band powers; a theta/alpha ratio is not guaranteed to cancel reference effects. |
| 4-second windows with overlap are used for MAT feature extraction. | Supported by `src/eeg_cogstates/dataset.py`, which creates fixed-duration windows and defaults to 4-second windows with overlap. Dataset-specific segmentation for STEW/DS007262 is handled separately in `scripts/multi_dataset_pipeline.py`. |
| All preprocessing, feature selection, and normalization occur inside training folds for leakage-aware evaluation. | Mostly supported for SNWA and LOSO in `scripts/run_all_journal_upgrade.py` and `src/eeg_cogstates/modeling.py`. However, static external prediction CSVs are consumed without a clearly traced generator, so this claim is not fully auditable for DS007262 SNWA transfer. |
| The manuscript reports inner-fold SVM hyperparameter search and default `C=1`, `gamma=scale` in 78 percent of folds. | **Unsupported by the current scripts.** `src/eeg_cogstates/modeling.py` and `scripts/multi_dataset_pipeline.py` use fixed model definitions; no matching nested SVM grid-search ledger or 78 percent fold summary was found. |
| Full-feature MAT LOSO decoding achieves strong AUC around 0.796 using an SVM RBF model. | Supported by `outputs/models/metrics_loso.csv`, where SVM RBF reports AUC 0.7959948 and F1 0.518864 under LOSO. |
| Harmonized common-feature LOSO models perform well on MAT and STEW but poorly on DS007262. | Supported by `results/multi_dataset/all_metrics.csv`: MAT AUCs are roughly 0.708 to 0.736, STEW roughly 0.753 to 0.833, and DS007262 roughly 0.467 to 0.546 depending on model. |
| Full-model cross-dataset transfer is poor or near chance. | Supported by `results/multi_dataset/cross_dataset_transfer.csv`, where many train-to-dataset transfers are near 0.47 to 0.51 AUC, with limited exceptions such as STEW-to-MAT SVM around 0.607. |
| DS007262 null/negative transfer is supported by Bayesian evidence BF01=3.42 and TOST p=0.038. | **Unsupported by located executable evidence.** Scripts include some t-test/Bayes helper logic, but no clear result artifact or generation path for the exact BF01=3.42 and TOST p=0.038 claim was found. |
| SNWA near-transfer to DS007262 reports K=5 AUC 0.618, p=0.005 and K=8 AUC 0.613, p=0.003. | Weakly supported by static artifacts: `external_validation_ds007262/ds007262_low_high_predictions.csv` and `outputs_phd_revision/tables/sr9_external_ttest.csv` contain these values. The executable generator for the external SNWA predictions was not found, so provenance is incomplete. |
| SNWA selected eight biologically interpretable features including frontal theta/alpha ratio, frontal relative theta, parietal alpha, frontal Hjorth mobility, central theta/alpha ratio, occipital beta, entropy, and frontal absolute theta. | **Contradicted by current artifact evidence.** `outputs_journal_upgrade/tables/table_snwa_feature_stability.csv` lists top features such as `band_abs_Cz_beta`, `band_rel_O2_gamma`, `band_abs_F4_alpha`, `band_rel_T6_gamma`, and `stat_P3_ptp`, not the manuscript's stated feature set. |
| Feature-family stability percentages show relative spectral, absolute spectral, ratio, Hjorth, and connectivity families in the reported proportions. | **Not supported by the current stability table.** `outputs_journal_upgrade/tables/table_feature_family_stability.csv` reports raw appearance counts that do not directly match the manuscript's stated percentages. |
| Connectivity-only LOSO analysis produces AUC about 0.595 and fails equivalence testing. | Partially supported by `outputs_phd_revision/tables/sr10_connectivity_equiv.csv`, which reports mean AUC 0.5947532 and p=0.1272235. The manuscript's stated connectivity feature count differs from the artifact count: 171 in text versus 215 in the table. |
| Baseline resting features can predict which subjects will be difficult to classify. | Weak exploratory support only. `scripts/option_a_individual_variability.py` and `outputs_phd_revision/tables/subject_variability_results.csv` report no FDR-significant resting predictors and LOOCV Spearman rho 0.3234 with p=0.0544. This should remain framed as hypothesis-generating. |
| Participants with high resting Hjorth complexity and disrupted temporal-occipital connectivity may reflect hyperarousal/default-mode interference. | **Unsupported as a demonstrated mechanism.** The manuscript frames this partly as future work, which is appropriate. Existing code does not measure DMN interference, hyperarousal state, or causal saturation of fronto-parietal networks. |
| Source localization will test cortical generators of theta/alpha workload effects. | Not yet supported. `main.tex` source-localization methods/results are TODO/future sections, and no source-localization script or result artifact was found. |
| The topographic map reflects real spatial workload effects. | Weakly supported at best. Feature-level spatial effects may exist, but `scripts/finish_everything.py` creates a simulated topographic summary rather than a full auditable sensor/source topography pipeline. |
| Learning-curve and power-analysis claims justify stability around 16 to 20 subjects and future N targets. | Partially supported by scripts in `run_all_phd_revision_tests.py` and `finish_everything.py`, but manuscript statements are internally inconsistent: one section reports N=86 for detecting rho=0.30, while a figure caption references N>=200. |
| Clinical or real-world thresholding can achieve approximately 90 percent sensitivity with about 60 percent specificity. | **Unsupported by located executable evidence.** Calibration utilities exist, but no clearly matched threshold table for the exact sensitivity/specificity claim was found. |
| Repository availability is correctly reported. | **Incorrect in `main.tex`.** The manuscript lists `https://github.com/agangarapu/eeg-workload-replication`, which does not match the current repository `CoderAwesomeAbhi/EEGARUSH`. |
