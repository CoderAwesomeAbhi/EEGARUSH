To deposit on Zenodo/OSF:

1. Go to https://zenodo.org/deposit/new
2. Upload the entire repository folder as a ZIP
3. Use the metadata in .zenodo.json as a starting point
4. Key files to feature:
   - paper/pdf/main.pdf — manuscript
   - outputs_reproduced/features/eeg_features.csv — derived feature table
   - outputs_journal_upgrade/tables/ — all analysis tables
   - outputs_phd_revision/tables/ — statistical audit results
   - results/multi_dataset/ — cross-dataset comparison
5. Set DOI to link to GitHub: https://github.com/abhij/<repo-name>
6. Under "Related/alternate identifiers" add the GitHub repo URL
