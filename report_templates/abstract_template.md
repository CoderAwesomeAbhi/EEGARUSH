# Abstract Template

Electroencephalography (EEG) provides a noninvasive way to measure neural activity associated with cognitive state. This project investigated whether machine learning models could classify baseline/rest EEG versus mental arithmetic workload using spectral, statistical, and channel-correlation features. EEG data were segmented into overlapping windows, and features were extracted from canonical frequency bands including delta, theta, alpha, beta, and gamma, along with time-domain statistics, entropy measures, Hjorth parameters, and inter-channel correlations. Multiple supervised classifiers, including logistic regression, random forest, support vector machines, gradient boosting, and XGBoost, were trained and evaluated using subject-wise splits to reduce data leakage. Statistical testing compared subject-level rest and workload features using paired tests, effect sizes, and FDR correction. Model performance was assessed using accuracy, sensitivity, specificity, positive predictive value, negative predictive value, F1-score, ROC-AUC, precision-recall AUC, and bootstrap confidence intervals. This end-to-end pipeline demonstrates how EEG signal processing, statistical analysis, and machine learning can be integrated to classify cognitive workload from neural activity.
